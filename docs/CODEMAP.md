# Code map (for agents)

Pointers, not prose. Paths under `godot/` are written from `godot/` (`src/...` = `godot/src/...`). Test names: `E:` =
`godot/tests/engine/`, `L:` = `godot/tests/legacy/`. "Doc" is the file that owns the topic: read it before changing the system,
update it in the same change.

## Layout

- `godot/src/{autoload,core,resources,rules,gameplay,problems,story,ui,skins,audio,checks,packs,mods,debug}`; `godot/addons/` (our editor
  plugins + gdUnit4, `midi/`, `godot_ai/`; `godot_sandbox/` is fetched, git-ignored); `godot/skins/{original,creatures}`; `godot/packs/{dev (committed),legacy (importer
  output, git-ignored)}`; `godot/data/` (project-level data); `godot/names/original.json` (name registry); `godot/tests/{engine,legacy,
  skins,fixtures}` + shared helpers.
- `tools/import/` (importer `import_all.py`, steps `step_*.py`, reset tools `reset_*.py`, `rename_name.py`), `tools/extract/`,
  `tools/analysis/` (+ `ghidra/`), `tools/dev_pack/`, `tools/gamefiles.py` (ISO reader), `tools/godot.sh`, `tools/run_tests.sh`, `tools/fetch_sandbox.py` (the pinned godot-sandbox extension; test `tools/test_fetch_sandbox.py`), `tools/fetch_export_templates.py` (Godot's export templates; test `tools/test_fetch_export_templates.py`).
- `mise.toml` (pinned tools; tasks `setup` (also fetches godot-sandbox), `sandbox:fetch`, `godot:import`, `godot:editor`, `godot:play <id>`, `godot:pack <id>` (`<id>.larissa` into the current directory or `--out`), `skin:templates` (the art templates into `skin_templates` or `--out`), `examples:pack <id>` (`<id>.larissa` of `examples/packs/<id>` into the current directory or `--out`), `examples:install <id>` (that folder into `user://packs/`), `test:engine`, `test:legacy`, `lint:tools`, `legacy:checktools`, `legacy:import`, `godot:fetch_templates`, `release:build_linux` (Linux export + `legacy.larissa` into `build/game`), `release:build_web` (Web export + `legacy.larissa` into `build/web`), `release:build` (both), `release:play`, `ghidra:import`, `ghidra:gui`, `ghidra:export`); `mise.proton.toml` (opt-in, `mise -E proton run ...`: run the original under Proton; `docs/SETUP.md`).
- `examples/packs/<id>/` (example packs, pack folders outside the project: `modern` = a skin with no script, `skin/` with its shaders, font and the HUD templates; `mise run examples:pack|install <id>`; test `E: test_example_pack_modern`).
- `docs/{play,create,engine,port}/`, `docs/data/` (analysis facts, committed; six ISO tables, ignored).
