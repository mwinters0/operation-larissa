# Fonts

`LiberationSans-Bold.ttf` (SIL Open Font License 1.1, see `LiberationSans-LICENSE.txt`) is the stand-in for
**Arial Bold**, the font of the original's problem screen (the game builds a GDI font from NEP.DLL strings
11253-11256: face "Arial", weight 700, cell height 19 px, average width 7 px). Liberation Sans is
metric-compatible with Arial, so line breaks and number boxes come out like the original's.
Not generated by the import pipeline: copied once from the system's `liberation-sans-fonts` package.
