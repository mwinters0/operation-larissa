# Operation Larissa - the Godot project

The Godot 4.7.2 project of the port (GL Compatibility renderer, 640 x 400 base viewport, integer scaling). Run it from the repository
root with `tools/godot.sh --path godot`; open the editor with `tools/godot.sh --editor --path godot`.
